# Generator New Generation

Приложение для Windows с GUI на `PyQt6` для генерации "сырых" данных датчиков,
их интерактивного редактирования на графике и сохранения в `txt`.

## Стек

- Python 3.11+
- PyQt6
- pyqtgraph
- numpy
- pandas

## Архитектура

- `core` содержит доменные модели, интерфейсы и историю редактирования.
- `tasks` содержит отдельные задания-датчики.
- `services` координирует генерацию, редактирование и экспорт.
- `ui` содержит окно, формы параметров и виджеты.
- `plotting` изолирует график и инструменты редактирования.

## Запуск

```powershell
python -m pip install -e .
python -m generator_app
```
